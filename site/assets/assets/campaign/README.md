# 山河复归图：地理、进度与来源

这是个人复习中心的互动地图。视觉和北伐意象参考《绍宋》，每个地名来自可追溯的历史治所记录；围绕治所绘制的分格是学习进度区域，不是宋代州县界，也不代表某一年南宋与金、辽等政权的实际控制区。

## 进度怎样计算

所有课程共用一张地图，计算规则为：

`进度 = 当前题库中已保存的“本轮已复习”题数 savedReviewed ÷ 当前题库总题数 total`

- 只计保存成功的完成状态。正在保存或保存失败的点亮状态不会提前增加红色面积。
- 同一道题只计一次；取消“本轮已复习”并保存后，比例与面积相应回退。“还不会”与完成状态独立，可以同时保留。
- 固定南方朱红区域为起始根据地。新增朱红面积等于进度乘以全部待收复区域的可见面积，按由南向北的固定顺序推进；前沿格可部分填色，不要求凑满整格才变化。
- 比例针对图中投影后的可见面积计算，不是地球表面的测绘面积。分格经过大陆海岸与起始根据地裁剪；复杂形状拆为无孔三角片，用面积求解前沿位置。
- 203个地名格是固定的地图设计精度，与题目数量无关。添加、删除或更新课程只改变当前题库分母与有效完成数，不重新生成地图、改名或重排地块。
- 例如已复习10/20题时，待收复区域的50%变红；扩充到40题且已复习仍为10题时，变为25%。这表示新增内容需要继续复习，原有笔记和有效完成状态仍保留。

军报也按当前百分比判断是否解锁，不保存一个与题库脱离的固定题数关卡。页面中的“当前需多少题”由总题数与百分比临时换算。当前题库全部点亮表示本轮复习完成，不自动等同于已熟练掌握。

## 地名与地图

[地名来源说明](地名来源说明.md)记录完整筛选条件、原始文件摘要及许可原文差异。

- 点库来自Harvard / Fudan CHGIS经TGAZ公布的CSV，以`BEG <= 1080 <= END`筛得该参考年存续的治所名称与同一源记录坐标。
- 658个去重治所点中，构建脚本按地理分布确定性采样203点，保留府等主要治所，再用最远点采样填充空间；没有为凑名字插入虚构地名或现代坐标。
- 1080年涵盖北宋与辽等并立地区，不能把全部地名解释成当年北宋领土，更不能冒充南宋当年的完整政区表。
- 每格保留源记录ID、名称、经纬度、存续区间、CSV行号和出处。放大地图可查看更密集的标签，拖动查看局部，点击地格查看名称、坐标与CHGIS来源。
- `viewBox="0 0 960 760"`；范围约东经105–122°、北纬23–41°。自然陆地轮廓来自Natural Earth，海岛未设成待收复目标。没有现代省界或人工宋金疆界。
- 南方根据地、简化河流和填色顺序均为复习玩法的设计。河流不代表宋代实际河道，地名点也不用于认定具体古城遗址。

## 32封北伐军报

`rewards-v2.json`提供32封军报，阈值覆盖1%至100%，比旧版9封增加到三倍以上。其中29封引用两宋之际、南宋及南宋遗民作者诗词，3封为郾城、颍昌、采石的历史回声。军报不局限于大捷，也包含勤学、守节、耐心与身体力行。

标题、印记名称与学习勉励为本站原创，不冒充《绍宋》角色台词。诗句署作者、篇名与出处，存在署名争议或版本差异的沿用注记；历史回声只采用可核基本史事，不把解锁顺序声称为实际战史。逐条内容见[奖励文案来源](奖励文案来源.md)。

《绍宋》叙事背景参考作者关于八公山的[访谈](https://www.chinawriter.com.cn/n1/2026/0714/c404024-40760284.html)、[第四卷卷末总结](https://www.xxsy.net/chapter/15610037104915904/49880803538612784)及[《获鹿》公开预览](https://www.xs.cn/chapter/15610037104915904/53918279106274074)。这些材料说明视觉与北伐意象，不覆盖CHGIS地名、地界或真实历史的证据来源。

## 离线文件与重建

- `../../campaign-data.json`：浏览器所需的固定地图几何、203格来源与32封军报，无在线地图服务依赖。
- `map-initial.svg`：初始配色和历史地名的静态参考图。
- `historical-places.json`：658点历史治所库。
- `rewards-v2.json`：32封军报、比例阈值及每条引用出处。
- `ne_50m_land.source.geojson`：原始Natural Earth海岸陆地数据，保持原文件。
- `tgaz_chgis_2016-07-06.source.csv`：历史地名原始CSV；随附其字段说明与GPL原文。
- `build_campaign.py`：离线构建脚本，读取以上本地输入并输出地图JSON和静态SVG；不读取或改写个人复习记录。

几何构建需要Shapely 2.1以上；当前使用Shapely 2.2.0及其NumPy依赖，均位于本项目`.runtime/geometry-deps`，没有安装进全局Python环境。当前Windows扩展为Python 3.13的64位版本，应使用匹配解释器。页面日常运行不需要导入这些GIS库。

在复习中心根目录打开PowerShell，可使用本机启动器同目录的Python 3.13执行：

```powershell
$reviewPython = Join-Path $env:LOCALAPPDATA 'Programs\Python\Python313\python.exe'
& $reviewPython .\web\assets\campaign\build_campaign.py
& $reviewPython -m unittest discover -s .\tests -p test_campaign_geometry.py
node .\tests\test_campaign_geometry.mjs
```

脚本按自身位置寻找`.runtime/geometry-deps`，无需改全局`PYTHONPATH`。迁移电脑重建时，应在该项目目录中准备与解释器版本、操作系统匹配的依赖，不能直接把本机的`.pyd`当作通用包。生成器与测试核对所有格的真实来源身份、唯一地名、海岸及根据地裁剪、覆盖无重叠，以及连续填色的面积比例。
