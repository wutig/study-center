# 首页素材

图像由用户提供的《绍宋》画面经内置图像编辑工具处理：`hero-scene.png` 去除左上角计时器；`hero-figure.png` 为透明人物层。页面用淡化场景、毛笔诗词、人物前景三层合成。原始上传图片没有覆盖。

界面采用朱红、墨色、纸白。它是参考画面后的设计取色，并非官方固定色板；官方人设及出版物料也包含其他颜色。

- [腾讯动漫作品页](https://ac.qq.com/Comic/comicInfo/id/651912)
- [官方人设物料](https://ac.qq.com/ComicView/index/id/651912/cid/883)
- [中信墨狸《绍宋·贰》出版物料](https://www.sina.cn/news/detail/5192355990214471.html)

毛笔字体为 Google Fonts 的 Ma Shan Zheng，字体及 SIL OFL 1.1 许可证位于相邻 `../fonts/` 目录，可随本地应用离线分发；未安装到系统。
