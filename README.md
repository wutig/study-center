# 复习中心 · 手机与平板公网版

保留五门课程的题目、详解、原图，以及逐题标记、可折叠答案和截图笔记。静态网站由 GitHub Pages 免费托管，电脑关机后仍可在手机浏览器打开。

每题点击「展开原题图片」即可在正文内显示原图，继续向下就能读解析；再次点击收起。筛选栏的「展开全部原图」只作用于当前显示的题目，图片、答案和笔记分别控制；「放大查看」仍可核对细节。

手机与窄分屏将原图批量按钮单独放一行，答案和笔记各占半行；平板横屏三项并列。触控区域至少48px，图片按可用宽度显示，长图底部也能直接收起并回到折叠栏。

题库文件使用 AES-256-GCM 加密后发布。解锁密钥通过个人入口链接的 URL 片段传递，不在公开仓库中。公开仓库不包含个人笔记、截图笔记或电脑的配对口令。

标记、进度和新笔记保存在当前浏览器的 IndexedDB 中。不同设备分别保存，使用「备份记录」和「恢复备份」迁移，不能自动同步。清除网站数据前，请先备份。

在 iPhone Safari 打开个人入口后，可通过「分享 → 添加到主屏幕」添加图标。若主屏幕 App 重新要求解锁，使用原个人入口中的解锁密钥。

vivo Pad5 等 Android 平板使用同一个网址。平板横屏采用左侧题目目录、右侧阅读正文；竖屏或分屏时收起目录。可使用个人链接中的 `?layout=tablet` 强制选择平板布局。建议在 Chrome 或 Edge 打开，通过浏览器菜单添加到主屏幕。平板具体操作见 [Android平板使用说明.md](Android平板使用说明.md)。

## 维护

`client/` 是静态存储与解锁代码，`build.mjs` 从本机复习中心构建 `site/`。构建密钥保存在被 Git 忽略的 `.private/` 中，请另行妥善保留。后续更新沿用同一密钥和题目 ID，不会清空已保存的浏览器记录。

GitHub Actions 发布 `site/` 到 Pages。此仓库仅用于个人课程复习。
